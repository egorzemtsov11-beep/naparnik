# Студия «Напарник»: запуск сайта

В архиве:
- `index.html` — сам сайт, один файл.
- `apps-script/Code.gs` — скрипт, который пересылает заявки с сайта вам в Telegram.

Всё делается за 20–30 минут, бесплатно. Шаги 1–2 запускают сайт, шаги 3–5 включают заявки в Telegram.

---

## 1. Создайте репозиторий на GitHub

1. Откройте github.com → **New repository**.
2. Название: `naparnik`. Тип: **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите `index.html`. Нажмите **Commit changes**.

## 2. Включите GitHub Pages

1. В репозитории: **Settings → Pages**.
2. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/naparnik/`.

На этом этапе сайт уже работает. Форма пока собирает заявку в текст, который клиент копирует и отправляет вам сам.

## 3. Создайте Telegram-бота

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: `Напарник: заявки`. Логин: любой свободный, например `naparnik_leads_bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Никому его не показывайте и не вставляйте в `index.html`.
4. Откройте своего бота и нажмите **Start**. Без этого бот не сможет вам писать.

## 4. Разверните скрипт в Google Apps Script

1. Откройте script.google.com под egorzemtsov11@gmail.com → **Новый проект**. Назовите его «Напарник: заявки».
2. Удалите всё в редакторе и вставьте содержимое `apps-script/Code.gs`. Сохраните.
3. **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** → добавьте:
   - `TG_TOKEN` = токен от BotFather
4. Вернитесь в редактор, выберите функцию **findChatId** → **Выполнить**. Google попросит доступ, разрешите. В журнале появится строка «Ваш chat id: …».
5. Снова в **Свойства скрипта** добавьте:
   - `TG_CHAT` = это число
6. Выберите функцию **testLead** → **Выполнить**. В Telegram должна прийти тестовая заявка.
7. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**:
   - Запуск от имени: **Я**
   - Доступ: **Все**
   - **Развернуть**. Скопируйте **URL веб-приложения** (оканчивается на `/exec`).

Необязательно: чтобы заявки дублировались в таблицу, создайте Google-таблицу и добавьте свойство `SHEET_ID` с её id (часть адреса между `/d/` и `/edit`).

## 5. Подключите форму к скрипту

1. В GitHub откройте `index.html` → значок карандаша.
2. Найдите строку `const LEAD_ENDPOINT = '';` и вставьте между кавычками URL из шага 4.7.
3. **Commit changes**. Через минуту отправьте заявку с сайта и проверьте Telegram.

---

## Потом

- **Свой домен** (например `naparnik.ru`): купите у регистратора, добавьте его в **Settings → Pages → Custom domain** и пропишите DNS-записи, которые GitHub покажет на этой странице.
- **Изменения на сайте**: правьте `index.html` прямо в GitHub, сайт обновится сам.
